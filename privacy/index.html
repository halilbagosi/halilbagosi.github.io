Privacy Policy

Effective 17 October 2026

The short version: Snippets collects no personal data. It has no accounts, analytics, advertising or tracking, and it never sends your snippets to me or to anyone else. Everything you create stays on your Mac.

This policy covers the Snippets app for macOS and this website. It is provided by Halil Bagosi, the developer of Snippets, based in Albania (“I”, “me”).

What I collect

Nothing. Snippets does not collect, transmit or sell any information about you or how you use it. There is no crash reporting, usage analytics or telemetry built into the app, and I have no server that receives data from it.

What stays on your Mac

Snippets stores what you create locally, on your Mac only:

  • Your library: snippets, collections, connections, attached images and videos, and saved preview settings, in the app’s data store in your user Library.
  • Your settings: appearance, preview and clipboard preferences, in the app’s standard macOS preferences.
  • Swift preview builds: compiled previews are cached locally so unchanged code runs instantly.

I cannot see or access any of this. Deleting a snippet moves it to Trash in the app; emptying Trash removes it. To remove everything, delete the app and its data from your user Library.

Export files: when you export snippets, the .snippets file is saved wherever you choose. What happens to it after that is up to you.

When Snippets uses the network

Snippets itself does not contact any server. There is one exception, which you turn on for each snippet separately:

  • npm packages from esm.sh. If a web preview imports npm packages and you allow that snippet to load them, the preview downloads those packages from esm.sh, a third-party service. Like any web request, esm.sh receives your IP address and the names of the packages requested. Its handling of that is governed by its own terms, not this policy.

Your own code: previewing a snippet runs it. If the code you write or paste makes network requests, for example a Swift program that fetches a URL, those requests come from your code. Snippets does not inspect, block or log them.

Clipboard

Offer to Save Copied Code is off by default. If you turn it on in Settings, Snippets checks the clipboard once a second, on your Mac, to see whether what you copied looks like code. If it does, the app offers to save it as a snippet.

  • Content that other apps mark as concealed, transient or auto-generated, as password managers do, is never read.
  • A suggested snippet is held in memory only and is not saved unless you choose to save it.
  • Clipboard contents never leave your Mac.

Shortcuts and Siri

Snippets offers actions to Shortcuts and Siri. When you use them, macOS handles your request as described in Apple’s Privacy Policy. Snippets only answers the request on your Mac.

This website

This site is hosted by GitHub Pages. It uses no cookies, analytics or trackers of its own. GitHub may log visitors’ IP addresses for security and operations, as described in the GitHub Privacy Statement.

If you email me for support, I use your email address and what you send only to reply and to fix the problem you report. I don’t share it, and I delete it when it is no longer needed for that.

Your rights

Because Snippets collects no personal data, there is normally nothing for me to access, correct or delete. If you have emailed me, you can ask me to show you or delete that correspondence at any time. Depending on where you live, data protection laws such as the GDPR or Albania’s Law on Personal Data Protection may give you further rights, and you can complain to your local data protection authority.

Children

Snippets is a developer tool and is not directed at children. It collects no data from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date. If Snippets ever starts collecting data, the policy will say so before that version of the app is released.
