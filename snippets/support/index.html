Common questions

What do I need to run Snippets?

A Mac running macOS 26 or later. To preview Swift snippets you also need Xcode installed. Snippets finds the Swift compiler through xcrun, so it uses whichever Xcode xcode-select points to.

Why doesn’t my preview run on its own?

Previewing a snippet runs its code, so by default Snippets waits for you to press Run. To run web and Metal previews automatically, turn on Run Previews Automatically in Settings ▸ Preferences. Swift previews always wait for you to press Run, whatever the setting says.

A preview says it needs packages from esm.sh

Web snippets that import npm packages (such as framer-motion or gsap) load them from esm.sh. Snippets asks you first, separately for each snippet, with a banner naming the packages. Allow it to run the preview. This is the only way a preview reaches the internet, and it needs a connection.

My Swift preview doesn’t compile
  • Only macOS code works. UIKit and iOS-only APIs won’t compile.
  • A view must be creatable with no arguments. If yours needs arguments, add a #Preview { … } block that creates it.
  • A type from another snippet is only found if that snippet is one of this snippet’s connections (editor ▸ connections).
  • Errors point at the line, e.g. snippet:12:5. Common mistakes come with a hint.
Snippets quit when I ran a Swift preview

A SwiftUI view preview runs inside Snippets itself, so a crash in the view, such as force-unwrapping nil, takes the app down with it. Your library is safe; reopen Snippets and fix the code. Console programs run separately, so a crash there only ends that run.

How do I back up my library or move it to another Mac?

Choose File ▸ Export Library… (⇧⌘E) to save every snippet, with its collections, connections, preview settings and media, to one .snippets file. On the other Mac, choose File ▸ Import Snippets… (⇧⌘I) or just open the file. If a snippet already exists, you can skip it, replace it, or stop.

I deleted a snippet by mistake

Deleted snippets go to Trash in the sidebar first. Open Trash and restore it from there.

How does saving copied code work?

Turn on Offer to Save Copied Code in Settings ▸ Preferences. When you copy something in another app that looks like code, Snippets offers to save it. It ignores anything password managers and other apps mark as private, and it saves nothing unless you choose to.

How do I copy a snippet without switching apps?

Click the scissors icon in the menu bar. Type to search, use ↑ and ↓ to choose, and press ⏎ to copy. ⌘1–⌘4 switch between Favorites, Frequent, Recent and All, and ⌘⏎ opens the snippet in the main window.

I closed the window but Snippets is still running

That’s intended: Snippets stays in the menu bar so quick copy keeps working. To quit, open the menu bar panel and click Quit in its footer, or press ⌘Q while Snippets is the active app.

Can I use Snippets from Shortcuts or Siri?

Yes. Snippets offers actions to create, find, copy, open and favorite snippets. Find them in the Shortcuts app under Snippets.

Does Snippets collect my data?

No. Everything stays on your Mac. See the Privacy Policy.
